AI agents

Let your AI trade.Within rules it can’t break.

Connect Claude or any agent that speaks MCP. It can check tokens and trade inside your wallet. The limits are enforced by our contract and our server, never by trusting the AI.

  1. 1Add Qalibre

    In Claude, add a custom connector with the address below. Other agents use a key from /agent in @QalibreBot.

  2. 2Approve in Telegram

    Check the pairing code matches, then allow trading or read only. You can revoke it any time.

  3. 3Ask

    Talk to it normally. Every trade it makes is announced to you in Telegram.

Setup

Claude, on the web, desktop or phone: open Settings, then Connectors, then Add custom connector, and paste this address. Tap Connect and approve in Telegram. There is no key to copy.

https://app.qalibre.app/mcp

Claude Code, or any client that takes a key

claude mcp add --transport http qalibre https://app.qalibre.app/mcp --header "Authorization: Bearer YOUR_KEY"

Cursor, VS Code and other MCP clients

{
  "mcpServers": {
    "qalibre": {
      "url": "https://app.qalibre.app/mcp",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}

Then ask

Check my Qalibre wallet and tell me what I hold.
Check this token on Qalibre and explain the risks: 0x…
If it checks out, buy 0.2 QMS of it on Qalibre and show me the result.
What an agent can do
  • Read your balances, holdings and orders
  • Run the safety check on any token
  • Quote a trade at the live price
  • Buy tokens you have approved, and sell back to QMS
What it can never do
  • Withdraw or send money out of your wallet
  • Buy a token you have not approved, or one rated high risk
  • Spend more than 1 QMS a trade or 5 QMS a day
  • Settle a trade below a direct swap

Revoke a key at any time with /agent. Keys expire after 90 days, and we store only a fingerprint of each one, never the key itself.
